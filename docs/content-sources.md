Source SHA-256, selection rules and interpretation boundaries are recorded in `docs/crowd-evidence.md`. The earlier hotspot screenshot and its risk annotations are not used.

The source project uses CCTV trajectories and contact data from Lyon's Festival of Lights. These are presented as analysis and simulation material; the portfolio does not claim that its author collected the event data. The original data license should be checked before any further redistribution of the dataset.

The project is a **research prototype**. The portfolio does not repeat improvement percentages from preset language-model responses or describe preset layout comparisons as an automatically optimized solution. The new figures parse the selected clip according to its header; broader project counts and speed conclusions remain unverified, and the previously cited count of 11,904 people is not used. Simulated potential contacts and observed contact events are distinct metrics. No record of an on-site intervention or independent calibration was found.

The homepage's native canvas is an **illustrative motion study**, not a calibrated simulator, an export of these trajectories or evidence of a project's measured performance. Its animation and pointer response should not be read as an engineering result.

## GR00T × Isaac Sim

The starting material is `GR00T/Isaac-Sim-with-Gr00t-Tutorial-main.zip` in the workspace. Its README matches the public [upstream tutorial](https://github.com/donghoYee/Isaac-Sim-with-Gr00t-Tutorial). Model and tooling references include [NVIDIA Isaac GR00T](https://github.com/NVIDIA/Isaac-GR00T). The tutorial targets N1.5; future experiments should pin compatible software, model and asset versions because the official main branch continues to evolve.

`assets/portfolio/groot.svg` is a code-native schematic created for this portfolio. It illustrates the relationship between data preparation, a policy service and simulation integration. It is **not an image of a tested robot**, a measured system output or evidence that a closed-loop task has succeeded. Third-party tutorial footage and screenshots are not presented as the author's project results.

The project is **engineering in progress**. The downloadable `assets/downloads/groot-completion.zip` contains the project's engineering package. Seven CPU protocol tests pass. Preflight checks, protocol tests, mock responses and launch scripts document engineering preparation; real-model inference, GPU training and Isaac Sim closed-loop evaluation remain unverified. Future results should include configurations, logs, task videos and experiment records. The portfolio does not claim a task success rate, successful closed-loop manipulation or a physical-robot deployment.
