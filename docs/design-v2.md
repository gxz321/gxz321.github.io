# Intelligence, in motion.

An English research portfolio for GXZ, designed around one relationship: people, space, and intelligent systems. The visual direction is an editorial field notebook rather than a list of interchangeable project cards.

## Design system

- Paper #f3f4ef, ink #161b18, acid accent #dfff00, secondary text #656b63. Flat colors; no decorative gradients or glow.
- Self-hosted Manrope variable font for editorial typography, Instrument Serif Italic for the single expressive word motion, and system monospace for metadata. Licenses ship with the fonts.
- 56px desktop gutters, 1440px maximum content; 20px mobile gutters. Sharp media corners, 1px rules, open layouts.
- A typographic first line across the page, a smaller second line to the left of a native flow canvas, a dark featured project, two open secondary studies, a compact forthcoming project, a working-method section, a chartreuse about band, and a dark contact footer.
- All UI text, controls, and navigation are real HTML. Native scrolling and focus are preserved.

## Concept references

The built-in ImageGen tool generated four coordinated concept screens before implementation. The files are retained in the workspace under website-research/design-v2: 01-home.png, 02-work.png, 03-approach.png, and 04-case.png. The concepts are implementation references, not backgrounds or project evidence.

The briefing specified: a Swiss editorial English personal portfolio; large neo-grotesk type and one italic serif word; near-white, charcoal, and acid chartreuse; a native pedestrian trajectory field; a full-width featured CrowdFlow study; two secondary GR00T and plaza studies; Observe / Model / Refine; Curiosity, made tangible; a GitHub contact footer; and a readable case-study layout with contents navigation. Fake metrics, affiliations, awards, template cards, gradients, glow, and hero eyebrows were prohibited.

## Interaction and content contract

The flow field is an illustration, never a calibrated crowd simulator. It has an explicit pause control, honors reduced motion, caps frame rate and pixel density, and stops when offscreen or hidden. Evidence switches show real artifacts and update their captions. Different plaza viewpoints are never described as a registered before/after comparison. GR00T workflow details distinguish verified protocol work from missing data and pending GPU evaluation.

Medical robotics is a compact forthcoming entry. No affiliation, qualification, personal role, email address, employment availability, or experimental outcome is invented. The website is entirely English; original research assets and source paths may retain their original language.

## Intentional adaptations

Actual research artifacts replace conceptual media slots. New crowd charts are generated deterministically from a named raw recording and describe trajectories or relative observation frequency, not crowd safety. The GR00T image is a native schematic. These adaptations preserve the design system while keeping evidence truthful.

## Verification standard

Review the complete desktop and mobile surface against the four concepts. Inspect typography, layout, spacing, colors, media, focus, movement, and copy. Exercise menu, pause, evidence switches, workflow disclosure, video, downloads, navigation, and 404. Check 320–1440px viewports, reduced motion, JavaScript disabled, keyboard use, internal links, English strings, console health, and resource sizes. Use independent visual review to identify concrete defects, then fix and retest them. Awwwards recognition is decided by its jury and is not a self-assigned result.
